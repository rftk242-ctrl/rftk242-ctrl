### 🐉 INTERACTIVE CREATURE ANIMATIONS

<img src="https://img.shields.io/badge/PROJECT-03-8B5CF6?style=for-the-badge"/>
<img src="https://img.shields.io/badge/STYLE-CREATIVE%20CODING-111827?style=for-the-badge"/>

**Turning a simple cursor into a living animation.**

An exploration of procedural 2D creatures that follow the cursor using smooth movement, articulated body segments, inverse kinematics, and coordinated limb motion.

**Visual goals**

- 🦎 Snake-like movement and follow-the-leader body physics.
- 🕷️ Coordinated legs and articulated creature anatomy.
- ⚡ Smooth motion with responsive cursor tracking.
- 🌑 Minimal dark backgrounds with luminous vector lines.
- 🎨 Procedural animation without relying on pre-rendered movement.

**Tech direction:** HTML5 Canvas · JavaScript · CSS · Inverse Kinematics
